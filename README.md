# vision-guard-patented-invention
A multi-purpose distance-measurement sensor system for safety and automation — from accident prevention to inventory counting.

## What it does
This project uses a distance-measurement sensor for four real-world applications:

1. **Vision health** — helps prevent sight issues before they develop
2. **Accessibility & safety** — helps prevent daily accidents for blind individuals
3. **Construction site safety** — monitors and maintains a required 25m safety distance between heavy machinery
4. **Industrial counting** — rapidly counts packets/items in a fabric or warehouse setting using distance sensing

## Why I built it
I noticed that a lot of people — myself included — develop sight issues from a small, everyday problem: sitting too close to devices, books, and screens. I built this ultrasonic distance sensored device to catch that problem early and prevent it, before it turns into a real vision issue. From there, I realized the same core sensing principle could solve other distance-related safety problems too — for blind individuals, construction sites, and industrial counting.

## How it works
Uses an ultrasonic sensor to measure distance via sound waves, adapting the same core sensing principle to four different applications — from safety alerts to automated counting.
